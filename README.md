🔎 OSINT Tool

A simple Python-based OSINT tool for gathering publicly available information.

«⚠️ Disclaimer: This project is intended for educational purposes and authorized security research only. Do not use it to harass, stalk, doxx, or access private information.»

✨ Features

- 🔍 Username investigation
- 🌐 Domain / website information
- 📡 IP information
- 📧 Email-related checks
- 🔗 Public-source lookup
- 🛠️ Command-line interface

📦 Requirements

- Python 3.x
- Internet connection
- Required Python packages listed in "osint.py"

🚀 Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY

Run the tool:

python osint.py

⚙️ Usage

python osint.py

Follow the instructions shown by the program.
