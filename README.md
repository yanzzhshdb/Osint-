⚡ About

OSINT.py is a command-line OSINT tool designed to help security researchers and developers gather information from publicly available sources.

The project focuses on keeping reconnaissance simple, lightweight, and easy to run from a terminal.

«🧠 OSINT = Open-Source Intelligence»

---

✨ Features

- 🔍 Username reconnaissance
- 🌐 Domain information
- 📡 IP information
- 📧 Public email-related checks
- 🔗 Public-source reconnaissance
- 🖥️ Command-line interface
- ⚡ Lightweight and fast
- 📱 Termux compatible
- 🐧 Linux compatible
- 🐍 Written in Python

🛡️ Responsible Use

This project is intended for:

- Security research
- Cybersecurity education
- OSINT learning
- CTF environments
- Authorized penetration testing
- Research using publicly available information

❌ Do not use this tool for:

- Doxxing
- Stalking
- Harassment
- Targeting private individuals
- Unauthorized access
- Collecting private or restricted information
- Any activity that violates applicable laws

Always obtain proper authorization before conducting security research on systems or accounts you do not own.

---

🔐 Privacy

OSINT tools should be used responsibly.

Only collect information that is legally accessible and publicly available. Respect privacy, terms of service, and applicable laws.
